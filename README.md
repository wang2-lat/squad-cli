# squad-cli

A lightweight CLI tool for managing small teams of 3-5 people.

## Problem It Solves

Designed for solo entrepreneurs or freelancers who are now managing 3-5 person teams. Common pain points:
- Team members not following through
- Can't find documentation
- No visibility into project progress
- Don't know who to hire next

## Features

- **Task Management**: Assign tasks, track status, and view all tasks
- **Document Indexing**: Index and search through team documentation
- **Team Analysis**: Analyze team composition and identify skill gaps
